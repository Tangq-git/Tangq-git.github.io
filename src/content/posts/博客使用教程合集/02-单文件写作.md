# 单文件写作方案

**一个 Markdown 文件 = 一篇文章**。在 `src/content/posts/` 下新建 `xxx.md`，写好 frontmatter，下面就是正文。

:::note
本篇就是单文件方案的活例子：在源码里找到 `posts/博客使用教程合集/02-单文件写作.md`，这篇文章本身就是一个文件。
:::

## 文件结构

```
src/content/posts/
├── 2026-10-26-我的第一篇博客.md      ← 单文件文章
├── 02-单文件写作.md                  ← 本篇（文件名就是 URL）
└── 03-文件夹写作/                    ← 文件夹方案见下篇
    └── index.md
```

文章访问地址：`/posts/02-单文件写作/`（文件名去掉 `.md`，含上级文件夹路径）。

## Frontmatter 字段速查

| 字段 | 必填 | 说明 |
|---|---|---|
| `title` | ✅ | 文章标题 |
| `description` | ✅ | 描述，显示在文章列表 |
| `published` | 建议 | 发布日期，格式 `2026-11-01` |
| `updated` | 否 | 更新日期 |
| `draft` | 否 | `true` = 草稿，线上不显示 |
| `pinned` | 否 | `true` = 置顶 |
| `tags` / `category` | 否 | 标签 / 分类 |
| `cover` | 否 | 封面图 URL 或路径 |
| `directoryTitle` | 否 | 侧栏目录里显示的名字 |

## 图片怎么放

单文件方案下图片**不能放在文章旁边**，两个选择：

1. **放 `public/` 目录**：图片放进 `public/images/`，正文写 `![描述](/images/xxx.png)`
2. **用外链图床**：直接写完整 URL

:::warning
单文件方案的本地图片在 RSS 里路径会出问题。文章图片多的话，用文件夹方案（见下篇）。
:::

## 什么时候用单文件

- 纯文字文章、笔记、教程
- 图片不超过一两张
- 图省事，不想建文件夹
